PLEGAR PRO v53.0 INDUSTRIAL STABLE

IDENTIDAD VISUAL
Se utiliza el primer concepto industrial aprobado: PP metálica con efecto de movimiento, fondo oscuro y acentos cian.

APERTURA
1. Descomprime el ZIP completo.
2. Abre index.html con Safari, Chrome, Edge o Firefox.
3. En iPhone/iPad es preferible abrirlo desde Safari o publicarlo en un servidor web. El visor interno de archivos puede restringir JavaScript.

ROBUSTEZ
- La pantalla inicial se retira mediante CSS incluso si JavaScript falla.
- Cada módulo es una página HTML real, por lo que la navegación no depende de JavaScript.
- Los formularios se guardan localmente cuando el navegador permite JavaScript.
- Los conectores propietarios y formatos cerrados requieren licencias/APIs oficiales.
